# Dataset Information

## Purpose
OceanGuard AI uses a pre-trained ONNX model for marine debris detection. The dataset below is a potential resource for future testing and evaluation.

## Potential Evaluation Dataset
- **Name:** Marine Debris Detection Dataset
- **Source:** Roboflow Universe
- **Link:** https://universe.roboflow.com/touseef-h4gwp/marine-debris-epuvm-fcecv

## Current Status
This dataset has not been confirmed as the training dataset for our downloaded ONNX model and has not yet been used to evaluate the current model.

## Important Notes
- Verify the dataset licence and usage terms before downloading or redistributing images.
- Check whether the dataset labels match the model's supported classes.
- Dataset availability does not imply that model training or evaluation has been completed.
